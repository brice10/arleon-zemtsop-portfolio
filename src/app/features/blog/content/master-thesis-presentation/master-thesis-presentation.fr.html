📚 La recherche

📄

Mémoire de Master

"Vers une approche d'ingénierie dirigée par les modèles pour la gestion des workflows dans une application Web"

Développement d'un framework d'application web intégrant la gestion des processus à l'aide d'un nouveau langage de spécification de processus opérationnels.

IDM Workflow LSAWfP DSL Web Apps

Mon travail se concentre sur le développement d'un framework d'application web qui intègre la gestion des processus métier en utilisant un nouveau langage de spécification de processus opérationnels appelé LSAWfP (Language for the Specification of Administrative Workflow Processes).

🔬 Contributions clés

Voici les principales contributions de mes recherches :

01

Proposition d'architecture logicielle

Proposition d'une architecture logicielle complète pour un système de création d'applications web incluant des capacités intégrées de gestion des processus métier.

02

Langage LSAWfP4WEB

Introduction de LSAWfP4WEB, un nouveau langage basé sur LSAWfP, spécifiquement conçu pour la spécification de processus métier basés sur le web.

03

Langage dédié embarqué (DSEL)

Développement d'un DSEL basé sur JSON pour la création, la sauvegarde et le partage de spécifications de workflow dans un format portable et standardisé.
