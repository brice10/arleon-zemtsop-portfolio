💻 The best compliment of my PhD life so far wasn't about my paper… it was about my code! 🥹

Hey everyone! 👋 Flashback: DisCoTec 2025, in Lille. I'm presenting my very first scientific publication, AdaptiFlow, in front of a room full of distributed systems experts. I survive the Q&A (despite my English doing its very best 😅) and I tell myself the hard part is over. 🎤

And yet, the real highlight came AFTER the session. ✨ Eddy Truyen, a renowned researcher in the field, walks up to me. He had read my paper (fair enough, so far). But he had also opened the source code and the documentation of the framework! 🔍 And he asks me a question nobody had ever asked me before: "Did you code AdaptiFlow and Adaptable TeaStore?". Yes, that was me. His answer: "That was really good code and excellent documentation". Cue internal me: fireworks! 🎇💥

Why did it touch me so much? Little confession: when I arrived in research, I quickly understood that many prototypes end up in a drawer once the paper is published. 🗄️ The code produces the charts, and then nobody opens it again. I just couldn't bring myself to do that! My engineering reflexes took over, and I treated this research code like production code:

  • documentation you can read without having to call me 📖
  • complete, ready-to-run examples with the Adaptable TeaStore test shop 🛒
  • clean code, with the Clean Code training by Raphaël Marvie at Inria still fresh in my mind (the Yoda of clean code, I stand by it 🧙‍♂️)
  • an open repository that anyone can clone and run 🌍

And no, this isn't just an ex-engineer being fussy! AdaptiFlow carries the word "extensible" in the title of my paper: a framework built so that others can plug their own adaptation ideas into it. Unreadable code would have turned that word into a lie. 😬

So yes, that compliment hit me harder than the paper acceptance itself, because it confirmed a conviction: a paper says what I did, my code proves I really did it 💡 In research, the code is not the paper's rough draft, it's the paper's evidence!

Thank you again to Eddy Truyen for that boost, and to my supervisors Simon Bliudze and Clément Quinton for the guidance that made all of this possible. 🙏🎓
