💻 Le plus beau compliment de ma vie de doctorant ne portait pas sur mon papier… mais sur mon code ! 🥹

Flashback : DisCoTec 2025, à Lille. Je présente ma toute première publication scientifique, AdaptiFlow, devant une salle d'experts en systèmes distribués. Je survis aux questions (malgré un anglais qui a fait ce qu'il a pu 😅) et je me dis que le plus dur est passé. 🎤

Et pourtant, le vrai moment fort est arrivé APRÈS la session. ✨ Eddy Truyen, un chercheur reconnu du domaine, vient me voir. Il a lu mon papier (jusque-là, normal). Mais il a aussi ouvert le code source et la documentation du framework ! 🔍 Et il me pose cette question que personne ne m'avait jamais posée : « Did you code AdaptiFlow and Adaptable TeaStore? ». Oui, c'est moi. Sa réponse : « That was really good code and excellent documentation ». À l'intérieur de moi : feu d'artifice ! 🎇💥

Pourquoi ça m'a autant touché ? Petite confidence : en arrivant dans la recherche, j'avais compris que beaucoup de prototypes finissent dans un tiroir une fois le papier publié. 🗄️ Le code sert à produire les courbes, et puis plus personne ne l'ouvre. Moi, je n'ai pas réussi à m'y faire ! Mes réflexes d'ingénieur ont pris le dessus, et j'ai traité ce code de recherche comme un code de production :

  • une documentation qu'on peut lire sans avoir besoin de m'appeler 📖
  • des exemples complets prêts à l'emploi, avec la boutique de test Adaptable TeaStore 🛒
  • du code propre, avec dans la tête la formation Clean Code de Raphaël Marvie suivie à Inria (le Yoda du code propre, je maintiens 🧙‍♂️)
  • un dépôt ouvert, que n'importe qui peut cloner et faire tourner 🌍

Et ce n'est pas du zèle d'ancien ingénieur ! AdaptiFlow porte le mot « extensible » dans le titre de mon papier : un framework fait pour que d'autres viennent y brancher leurs propres idées d'adaptation. Un code illisible aurait transformé ce mot en mensonge. 😬

Alors oui, ce compliment m'a fait plus d'effet que l'acceptation du papier lui-même, parce qu'il m'a confirmé une conviction : un article dit ce que j'ai fait, mon code prouve que je l'ai vraiment fait 💡 En recherche, le code n'est pas le brouillon du papier, c'est sa pièce à conviction !

Merci encore à Eddy Truyen pour ce coup de boost, et à mes encadrants Simon Bliudze et Clément Quinton pour le cadre qui a rendu tout ça possible. 🙏🎓
